KELLER-OS

A microkernel that boots to ring 3 and proves it. It replaces the 8259 with a Local APIC and an IO-APIC, starts its application processors with INIT-SIPI-SIPI, and drops into an unprivileged task whose own CPU frame testifies that it runs at CPL 3.

02 — the modulesWhat is actually in the kernel

Every line below is a module in src/ with a self-test that runs at boot and reports what it measured — including the hardware this machine does not have.

arch/lapic.rsThe Local APIC's timer is calibrated against the PIT, not against arithmetic. The reload the clock arithmetic predicts does not survive being measured, so the kernel probes a ladder of reloads, confirms the winner, and re-arms from its own handler.
arch/ioapic.rsInterrupts are routed through the IO-APIC with the 8259 masked behind it: 24 redirection entries written and read back, the timer delivered through the controller.
arch/smp.rsApplication processors are woken with INIT-SIPI-SIPI and handed their own GDT, TSS and IST stack. Each hashes a fixed workload and must agree on 5fa184c8…78ec — a hash no AP can fake by running a different code path.
paging.rs · idt.rsPer-process PML4s mean two tasks can use identical virtual addresses and reach different frames, so a cross-space read is a not-present page fault rather than a check the kernel has to remember to make. int 0x80 is the only DPL-3 gate in the table.
