Fundamental Kernel Principles

Eliminating monolithic kernel attack surfaces: KELLER-OS enforces formal capability limits and zero unbounded loops.

Allocation-Free Core

The entire core microkernel operates without dynamic memory allocators. All stacks, descriptor tables, and IPC buffers are statically bound at link time.

Cryptographic Vault Enclaves

Isolated execution domains communicate solely through unforgeable 256-bit cryptographic capability tokens verified by hardware MMU page tables.

QEMU & Bochs Test Harness

Fully reproducible automated headless VM validation verifies register state preservation across interrupt returns and context switches.

Terminal Quickstart

Build the sovereign kernel binary and run headless QEMU integration tests.

bash — cargo build & qemu 
git clone https://github.com/KELLERBABG/KELLER-OS.git
cd KELLER-OS
cargo build --offline -Zjson-target-spec
qemu-system-x86_64 -cpu max -m 256M -kernel target/x86_64-sovereign_core/debug/sovereign-core -serial stdio -display none
